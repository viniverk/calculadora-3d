# Servidor Printables (Netlify)

1. Netlify → **Add new site → Import an existing project → GitHub** → `viniverk/calculadora-3d`.
2. Em **Base directory** coloque `servidor-printables`. Deixe o comando de build vazio e o diretório de publicação `public`.
3. **Deploy**. Abra `https://SEU-SITE.netlify.app/search?q=benchy` para testar (deve mostrar um JSON).
4. Passe o endereço `https://SEU-SITE.netlify.app` para o app (constante `SERVIDOR_PRINTABLES`).
