🔄 Migração: Supabase → Firebase

Ferramenta de uso único. Rode isso uma vez para copiar seus dados do Supabase para o novo banco no Firestore. Depois de confirmar que tudo migrou certo, você pode fechar esta página — ela não precisa ficar no ar.

1. Login no Supabase (dados antigos) pendente
2. Login no Firebase (dados novos) pendente
3. Migrar os dados

Todos os registros migrados ficam associados à conta do Firebase logada no passo 2. Rodar mais de uma vez não duplica nada (os IDs originais são preservados).
